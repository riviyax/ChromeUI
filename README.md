# FoxUI 🦊

FoxUI is a lightweight, modern, and cross-browser new tab extension focused on a clean UI, exceptional performance, and simplicity. It transforms your default new tab page into a highly personalizable and fast workspace.

---

## 📦 Manual Installation Guide (GitHub Release)

If you are using Chrome, Edge (while in review), or prefer to load FoxUI manually as an unpacked developer extension/add-on, follow these steps:

### 1. Download the Release Archive
Head over to the **Releases** tab of this repository and download the specific `.zip` package for your browser:
* 📥 `FoxUI for Chrome-1.0.0.zip`
* 📥 `FoxUI for Edge-1.0.0.zip`
* 📥 `FoxUI for Firefox-1.0.0.zip` *(Optional, store link preferred)*

Once downloaded, extract the archive to a folder on your system.

---

### 2. Browser-Specific Setup

#### 🌐 Google Chrome
1. Open Google Chrome and navigate to `chrome://extensions`.
2. Enable **Developer Mode** using the toggle switch in the top-right corner.
3. Click on the **Load unpacked** button in the top-left corner.
4. Select the extracted `FoxUI for Chrome-1.0.0` folder.

#### 🌐 Microsoft Edge
1. Open Microsoft Edge and navigate to `edge://extensions`.
2. Toggle on **Developer mode** in the bottom-left pane.
3. Click the **Load unpacked** button.
4. Select the extracted `FoxUI for Edge-1.0.0` folder.
